# Moctar Sankara Portfolio

Static portfolio website prepared for GitHub Pages.

## Publish at sankaramoctar.github.io

1. Create a public GitHub repository named exactly `sankaramoctar.github.io`.
2. Copy everything inside the `dist` folder to the root of that repository.
3. Commit and push the files to the `main` branch.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, select **Deploy from a branch**.
6. Select the `main` branch and `/ (root)`, then click **Save**.
7. After GitHub finishes deploying, visit `https://sankaramoctar.github.io`.

The site does not require npm, a build process, a database, or environment variables.
